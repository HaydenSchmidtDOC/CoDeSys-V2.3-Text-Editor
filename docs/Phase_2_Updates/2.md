# DEMO_FIXTURE.pro — synthetic TwinCAT 2 / CoDeSys V2.3 project

A structurally complete `.pro` containing **no company data**, for offline
development of parsers and tooling.

## What it is

Generated from a real project by `sanitize.py`. Every identifier, comment,
label and line of logic is invented. Every *structural* feature is preserved,
so it exercises the same parser paths as the real thing.

| Feature | Value |
|---|---|
| Size | 335,392 bytes |
| Objects | 35 (27 POU, 8 GVL) |
| Bodies | 21 Structured Text, 6 Ladder |
| Ladder networks | 58 (2 / 13 / 7 / 20 / 10 / 6) |
| Folder tree | full nesting incl. 2 sub-folder levels |
| Tasks | 3, one deliberately **disabled** |
| Libraries | 6 references + 136-entry symbol index |
| Object IDs | preserved (bands 1–30, 677–744) |
| MARK collisions | present — exercises the maximal-run rule |
| Visualizations | 2 |

Verified: **122/122 invariants, zero failures, byte-exact no-op round-trip**;
all 58 ladder networks walk and re-encode exactly.

## What was removed

| Surface | Method |
|---|---|
| POU / GVL / variable names (1,235) | same-length synthetic identifiers |
| Symbol-cache + directory names (470) | renamed via each region's length prefix |
| Task-config names (4) | `u8`-prefix records |
| Ladder element names + comments | renamed through the element walker |
| ST declarations and bodies | regenerated wholesale, type-correct |
| Visualization labels, expressions, comments (482) | same-length neutral filler |
| Embedded absolute path / username | replaced with `C:\PLC\Demo\Synthetic\` |

Audited for 55 company terms (names, sites, project codes, domain vocabulary):
**zero hits**. Only `MAIN`, `Standard` and `Global_Variables` survive — CoDeSys
default names, not company data.

## Known limitation

Vendor library documentation strings inside the library symbol cache
(Beckhoff `Tc*.lib`, `COMlibV2.lib` — e.g. *"pointer to any KL6 or COM-Port
process image"*) are **deliberately preserved**. They are third-party API
documentation, identical in any project using those libraries, and removing
them would desynchronise the cache from the library references. If your
policy treats COMlibV2 as proprietary, re-run with the neutralisation range
extended to `(202, len(out))` and accept that library calls become opaque.

**Not opened in TwinCAT.** Structural validity is proven against the format
spec, but no round-trip through the real IDE has been done. Open a copy
first, and expect the compiler to reject the synthetic logic as meaningless
(it is syntactically valid, not functionally sensible).

## Regenerating

    python sanitize.py <real.pro> <synthetic.pro>
    python proparse.py verify <synthetic.pro>

`sanitize.py` is deterministic — the same input always yields the same
output, so fixtures are reproducible and diffable.
